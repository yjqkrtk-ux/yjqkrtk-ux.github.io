CHAPTER 04 · UNIVERSAL CFA (universal_cfa/ · SIMULATION TRACK)

Universal CFA — 위상 인식 인센서 압축과 고정 호스트 번역기

최신 50MP ~ 200MP 모바일 이미지 센서는 서브미크론 픽셀의 수광량 한계를 극복하기 위해 \(2\times 2\) Bayer 대신 같은 색 필터를 \(2\times 2\) 또는 \(4\times 4\)씩 묶어 배치하는 Tetracell (\(4\times 4\) 주기) 및 Hexadecacell (\(8\times 8\) 주기) 컬러 필터 배열(CFA)을 채택합니다. Universal CFA (`SE-Universal-CFA`) 연구 트랙은 고비용 리모자이킹(Remosaicing)과 RAW 전송을 생략하고, 센서별 위상 인식 SE-ResNet 압축기(\(\mathcal{E}_A^{\mathrm{CFA}}\))가 1채널 CFA 모자이크를 곧바로 호스트의 센서 불변 통합 번역기(\(\mathcal{T}_B: 16\to 16\))와 16채널 `FLUX.1` / `TAEF1` 디코더(\(\mathcal{D}_{\mathrm{rec}}\))가 공유하는 단일 16채널 버스 텐서 \(r \in \mathbb{R}^{16\times 64\times 64}\) (`64 KB` INT8)로 매핑하는 아키텍처를 탐구합니다.

지원 CFA Bayer (2×2) · Tetracell (4×4) · Hexadecacell (8×8) 센서 구조 3D 적층형 BSI CMOS + 인센서 NPU 핵심 연산자 PixelUnshuffle(r) + SE-ResBlock 호스트 파이프라인 16-Ch FLUX.1 / TAEF1 단일 스트림 통합

4.1 적층형 센서 구조와 군집형 CFA (Bayer · Tetracell · Hexadecacell)

픽셀 피치가 \(0.56\ \mu\text{m}\sim 0.7\ \mu\text{m}\) 수준으로 작아지면 개별 포토다이오드가 모으는 광자 수가 급감하여 저조도에서 샷 노이즈가 폭발합니다. 이를 해결하기 위해 현대 고화소 센서는 인접한 \(2\times 2\) 픽셀(Tetracell / Quad-Bayer, 전체 주기 \(4\times 4\))이나 \(4\times 4\) 픽셀(Hexadecacell / 16-Cell, 전체 주기 \(8\times 8\))에 동일한 색상의 컬러 필터를 씌우고, 픽셀 다이 바로 아래에 Cu-Cu 하이브리드 본딩으로 로직 및 인센서 NPU 다이를 적층합니다(cfa_physics.py).

3D 인터랙티브

마우스로 드래그해 3D 센서 스택을 회전시켜 보세요. CFA 패턴을 바꾸면 \(8\times 8\) 컬러 필터 어레이가 \(1\times 1\)(Bayer), \(2\times 2\)(Tetracell), \(4\times 4\)(Hexadecacell) 동색 클러스터로 즉시 재구성되며, 적층 레이어 분해 간격 슬라이더를 올리면 ① 마이크로렌즈 → ② 컬러 필터(CFA) → ③ DTI 실리콘 포토다이오드 → ④ Cu-Cu 하이브리드 본딩 → ⑤ 인센서 NPU 다이의 5계층 수직 구조를 펼쳐서 관찰할 수 있습니다.

기존 파이프라인의 이중 부담: Remosaic + Demosaic

저조도에서는 동색 픽셀을 합산(Binning)해 일반 Bayer처럼 읽지만, 주광에서 전체 해상도를 살리려면 군집형 모자이크를 다시 표준 \(2\times 2\) Bayer 배열로 재배치하는 리모자이킹(Remosaicing)과 이를 다시 3채널 RGB로 바꾸는 디모자이킹(Demosaicing)을 연달아 수행해야 합니다. 특히 Hexadecacell에서는 같은 색 클러스터의 폭이 4픽셀에 달해 고주파 에지에서 심각한 의사색(False Color)과 지퍼 아티팩트가 발생합니다.

표준 Stride-2 합성곱의 위상 혼란 (Phase Shift)

1채널 CFA RAW에 곧바로 stride=2, kernel=4×4 합성곱을 적용하면 어떻게 될까요? Bayer(\(2\times 2\) 주기)에서는 커널이 2칸씩 이동할 때마다 항상 동일한 [R, Gr; Gb, B] 위상을 봅니다. 반면 Tetracell(\(4\times 4\))이나 Hexadecacell(\(8\times 8\))에서는 스트라이드 2 이동 시 커널이 위치는 달라도 전혀 다른 색 조합을 스캔하게 되어 단일 합성곱 필터가 공간 이동 불변성(Translation Equivariance)을 잃어버립니다.

4.2 인터랙티브 CFA 격자 & PixelUnshuffle 위상 분해 시뮬레이터

위상 불일치를 근본적으로 해결하는 연산이 PixelUnshuffle(r) (Space-to-Depth)입니다(phase_aware_compressor.py). CFA의 기본 주기 \(r \in \{2, 4, 8\}\)에 맞춰 입력 텐서 \(y_{\mathrm{CFA}} \in \mathbb{R}^{1\times H\times W}\)를 \(r^2\)개의 서브 위상 평면으로 분해하면, 각 채널은 오직 단일 색상·단일 위상의 샘플만 담게 되어 완벽한 공간 정렬이 이루어집니다:

$$\operatorname{PixelUnshuffle}_r : \mathbb{R}^{1\times H\times W} \;\longrightarrow\; \mathbb{R}^{r^2 \times \frac{H}{r} \times \frac{W}{r}}, \qquad r \in \{2\ (\text{Bayer}),\; 4\ (\text{Tetracell}),\; 8\ (\text{Hexadecacell})\}$$

위상 정렬 시각화

CFA 패턴과 커널 스캔 위치를 바꿔 보세요. 왼쪽은 \(8\times 8\) 센서 포토다이오드 격자 위에서 stride=2 커널이 어떤 색상 위상을 보는지 보여주며, 오른쪽은 PixelUnshuffle(r) 적용 후 생성되는 \(r^2\)개의 동색 위상 채널 구성을 보여줍니다.

4.3 단일 16채널 호스트 번역기(\(\mathcal{T}_B: 16\to 16\))와 센서별 위상 인식 압축기(\(\mathcal{E}_A^{\mathrm{CFA}}\))

스마트폰이나 엣지 제품군에서 카메라 센서 모듈(Bayer, Tetracell, Hexadecacell)이 바뀔 때마다 호스트 SoC의 대규모 번역기(\(\mathcal{T}_B\))와 다운스트림 디코더/확산 모델을 재학습·재컴파일하는 것은 막대한 엔지니어링 비용을 초래합니다. `SE-Universal-CFA`는 호스트의 16채널 번역기(\(\mathcal{T}_B: 16\to 16\))와 디코더(\(\mathcal{D}_{\mathrm{rec}}\))를 100% 센서 불변(Shared)으로 통합하고, 센서 다이 내부의 위상 인식 압축기 \(\mathcal{E}_A^{\mathrm{CFA}}\)만 해당 CFA의 주기 \(r\)에 맞춰 배치합니다:

$$r = \mathcal{E}_A^{\mathrm{CFA}}\!\big(y_{\mathrm{CFA}}\big) \in \mathbb{R}^{16\times 64\times 64}, \qquad \hat{z} = r + \mathcal{T}_B(r) \in \mathbb{R}^{16\times 64\times 64}$$
Ch.02의 LSP Stage A는 온칩 ISP가 만든 3채널 RGB(\(512\times 512\times 3\))를 입력받지만, Universal CFA의 \(\mathcal{E}_A^{\mathrm{CFA}}\)는 온칩 디모자이킹/리모자이킹 이전의 1채널 CFA 모자이크(\(512\times 512\times 1\))를 직접 입력받아 `HDRNet` / `Comp-LSP`와 동일한 16채널 `FLUX.1` / `TAEF1` 잠재 공간으로 직행합니다.

4.4 No-Raw-Retention 제약과 One-Pass 잠재 복원

학계의 많은 확산 기반 역문제 해법(예: DPS, DDRM 등)은 확산 디노이징 스텝 \(t = T, \dots, 1\)마다 관측 행렬 \(A\)(CFA 마스크)와 원본 RAW 측정치 \(y_{\mathrm{CFA}}\)를 참조해 데이터 일관성 기울기 \(\nabla_{x_t}\lVert y_{\mathrm{CFA}} - A\hat{x}_0(x_t)\rVert_2^2\)를 계산합니다.

왜 LSP 버스에서는 반복적 RAW 참조(Iterative Guidance)를 배제하는가?

우리 시스템의 핵심 전제는 호스트로 원본 RAW \(y_{\mathrm{CFA}}\)를 아예 전송하지 않고 64 KB 텐서 \(r\)만 보낸다(No-Raw-Retention)는 것입니다. 따라서 호스트는 복원 시점에 \(y_{\mathrm{CFA}}\)를 가지고 있지 않으며, 오직 \(\hat{z} = \mathcal{T}_B(r)\)만을 조건으로 삼아 단일 패스(One-Pass) 잠재 디코더(high_fidelity_decoder.py) 또는 잠재 조건부 확산 백본으로 최종 RGB 영상을 생성합니다.

시뮬레이션 범위 및 정합성 주의사항
  • 합성 CFA 입력: 현재 universal_cfa/ 실험의 입력은 물리 센서에서 직접 취득한 RAW가 아니라 RGB 이미지에서 cfa_physics.py로 샘플링한 시뮬레이션 데이터이며, IMX500 하드웨어 .rpk 배포 실측은 포함하지 않습니다.
  • 버스 지연 참조값: 결과 JSON(benchmark_summary.json)에 기록된 bus_latency_ms(2.9 ms / 52.91 ms)는 동일 페이로드 크기(64 KB vs 3,072 KB)를 갖는 Ch.02 LSP 하드웨어 실측값을 참조로 기입한 값입니다.
  • Latent Cosine “—” 표기: 픽셀 도메인 알고리즘 리모자이킹 경로는 잠재 텐서 \(\hat{z}\)를 생성하지 않으므로 벤치마크 스크립트(run_universal_benchmark.py)가 자리표시로 0.0을 기록하며, 표에서는 이를 —로 표시합니다.

핵심 정리 · Chapter 04

  • 군집형 CFA의 위상 문제: Tetracell(\(4\times 4\))과 Hexadecacell(\(8\times 8\))에 일반 스트라이드 합성곱을 적용하면 위치마다 서로 다른 색상 클러스터를 스캔하여 위상 정렬이 깨집니다.
  • PixelUnshuffle(\(r\)) + SE-ResBlock 위상 분해: 주기 \(r \in \{2, 4, 8\}\)로 입력 모자이크를 \(r^2\)개 채널로 언셔플한 뒤 `SE-ResBlock`을 적용해 모든 CFA 센서를 단일 16채널 버스 텐서 \(r \in \mathbb{R}^{16\times 64\times 64}\) (`64 KB` INT8)로 매핑합니다.
  • 100% 센서 불변 16채널 호스트 파이프라인: 센서 모듈이 바뀌어도 호스트의 16채널 번역기(\(\mathcal{T}_B: 16\to 16\))와 `TAEF1` + `SE-PixelShuffle` 디코더(\(\mathcal{D}_{\mathrm{rec}}\))는 100% 동일 가중치로 공유됩니다.
  • `FLUX.1` / `TAEF1` 16채널 잠재 정렬 및 고충실도 복원: `BJDD_CVPR21`에서 Bayer 29.43 dB, Tetracell 28.82 dB, Hexadecacell 27.38 dB (`Kodak24`에서 29.87 / 29.40 / 28.50 dB)를 달성합니다.

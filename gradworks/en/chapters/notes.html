Single-Source-of-Truth Build Principle & 7-Stage Automated Verification

The entire guidebook (docs/index.html, docs/chapters/*.html, docs/en/*, docs/isocell/*) is generated deterministically by docs/build_spec_portal.py rather than manual HTML editing, and must pass all seven integrity gates below before any deployment artifact is updated.

Gates 1–2 · Source Anchor & Token Integrity

Verifies disk existence and exact 1-based line anchors (#Lxx) for every src() call, ensures zero broken GitHub Pages <a href> links, and blocks any unfilled [[TOKEN]] placeholders.

Gates 3–5 · HTML DOM, KaTeX & SVG Bounds

Validates matching open/close tags via Python's HTMLParser, checks brace balance and non-ASCII purity across all LaTeX equations, and verifies every inline <svg> against box/text overflow.

Gates 6–7 · Privacy Gate & English Zero-Hangul

Aborts the build if any private reference under Documents/Personal/ or restricted personal identifier appears (Rule 5), and enforces zero Hangul characters across all English (en/, isocell/en/) HTML and JS assets.

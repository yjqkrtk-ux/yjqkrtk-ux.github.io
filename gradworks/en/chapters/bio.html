CHAPTER 02 · THEME 2 — BIOINFORMATICS & DEEP RL

Deep Reinforcement Learning Sequence Alignment (DQNAlign) & High-Speed Genomic Mining

As Next-Generation Sequencing (NGS) and third-generation long-read technologies (PacBio, Oxford Nanopore) produce single reads spanning tens to hundreds of kilobases (bp), the $O(N_1 N_2)$ spatiotemporal complexity of classical global dynamic programming (Needleman-Wunsch) has become a severe computational bottleneck. This chapter dissects Dr. Yongjoon Song's core Ph.D. dissertation breakthrough, DQNAlign (agent.py:10, Learning.py:17, IEEE OJEMB '21a ↗, IEEE OJEMB '21b ↗)—including its local sliding-window MDP formulation and Dueling Double DQN + Exact Match Skip hybrid accelerator—alongside the chromosome-scale repeat mining and clinical biomarker engines REminerII · PixelRE · REDNN (Insilico.py:74, PixelRE.m:3, REDNN.py:74, US 2019/0385696 A1 ↗).

  • Understand the Local Sliding-Window MDP and Exact Match Skip heuristic that overcome the $O(N_1 N_2)$ barrier of global Needleman-Wunsch dynamic programming.
  • Verify the mathematical formulations of Dueling Double DQN ($128+128$ stream split), Depthwise Separable Conv, and Zipfian ($s=1.6$) indel distributions.
  • Experiment directly with DQNAlign alignment trajectories and REminerII / PixelRE 2D dot-plot seed extension via Interactive Simulators 02 and 03.

Limits of Global Dynamic Programming & Local Sliding-Window MDP Formulation

When aligning two nucleotide sequences $S^{(1)} = (s^{(1)}_1, \dots, s^{(1)}_{N_1})$ and $S^{(2)} = (s^{(2)}_1, \dots, s^{(2)}_{N_2})$ ($s \in \{\text{A, C, G, T}\}$), Needleman-Wunsch global dynamic programming (AlignmentGenerator, QLOBAL) evaluates the following recurrence across every grid cell $(i, j) \in [0, N_1] \times [0, N_2]$:

$$F(i, j) = \max \begin{cases} F(i-1, j-1) + \sigma\!\left(s^{(1)}_i, s^{(2)}_j\right) & \text{(Match / Mismatch)} \\[4pt] F(i-1, j) - d_{\text{gap}} & \text{(Deletion in } S^{(2)}\text{)} \\[4pt] F(i, j-1) - d_{\text{gap}} & \text{(Insertion in } S^{(2)}\text{)} \end{cases}$$

If $N_1 = N_2 = 10^5\text{ bp}$, the DP grid contains $10^{10}$ cells (requiring roughly $40\text{ GB}$ of RAM at 4 bytes per integer), making single-node execution infeasible. Instead of materializing the full grid in memory, DQNAlign (alignment.py:9) reformulates sequence alignment as a Markov Decision Process (MDP) that observes only a forward-looking $W \times W$ local subsequence window (Local Sliding Window) as state $s_t$ at the current alignment head $(x_t, y_t)$ and sequentially selects the optimal action $a_t$.

MDP State, Action, Reward & Exact Match Skip Formulation

  • State Space ($\mathcal{S}$): alignment.py:110 and alignment.py:158 encode the local subsequence window starting from the current alignment coordinate $(x_t, y_t)$ as a one-hot tensor or 2D match map for neural network input.
  • Action Space ($\mathcal{A}$, n_action = 3): $$a_t \in \{0:\text{Forward } (x_t+1, y_t+1),\;\; 1:\text{Insertion } (x_t, y_t+1),\;\; 2:\text{Deletion } (x_t+1, y_t)\}$$
  • Reward Function ($\mathcal{R}$): $$r_t = \begin{cases} +r_{\text{match}} & \text{if } a_t = 0 \text{ and } s^{(1)}_{x_t} = s^{(2)}_{y_t} \\ -p_{\text{mismatch}} & \text{if } a_t = 0 \text{ and } s^{(1)}_{x_t} \neq s^{(2)}_{y_t} \\ -p_{\text{indel}} & \text{if } a_t \in \{1, 2\} \end{cases}$$
  • Exact Match Skip Accelerator (agent.py:82, agent.py:96, agent.py:110): In homologous genomic regions, consecutive exact nucleotide matches (Exact Match Runs) occur frequently. Agent.skip() advances diagonally in a tight loop without invoking the neural network as long as $s^{(1)}_{x_t} = s^{(2)}_{y_t}$, calling the Dueling Double DQN agent only at mismatch or indel boundaries.

Dueling Double DQN & Depthwise Separable Conv Architecture

Learning.py:17 implements the standard convolutional Qnetwork alongside the lightweight Depthwise Separable Convolution (Learning.py:88) SSDnetwork and differential-feature DiffSSDnetwork (Learning.py:171).

  1. Dueling Stream Split (Learning.py:52): The final convolutional feature vector $h \in \mathbb{R}^{256}$ (h_size = 256) is split evenly into an action-advantage stream $\text{streamAC} \in \mathbb{R}^{128}$ and a state-value stream $\text{streamVC} \in \mathbb{R}^{128}$, which are recombined into $Q(s, a; \theta)$ via: $$Q(s, a; \theta) = V(s; \theta_V) + \left( A(s, a; \theta_A) - \frac{1}{|\mathcal{A}|} \sum_{a'=0}^{|\mathcal{A}|-1} A(s, a'; \theta_A) \right)$$
  2. Double Q-Learning Target (agent.py:77): To prevent Q-value overestimation bias caused by single-network max operations, action selection uses the online network $\theta$ while value evaluation uses the target network $\theta^-$: $$y_t = r_t + \gamma \, Q\!\left(s_{t+1}, \arg\max_{a'} Q(s_{t+1}, a'; \theta_t);\; \theta^-_t\right), \quad \gamma = 0.99$$
  3. Polyak Soft Target Updates & Zipfian Indel Distribution (alignment.py:42): The target network is updated smoothly at every training step via $\theta^- \leftarrow \tau \theta + (1-\tau)\theta^-$ ($\tau = 0.001$), and indel lengths in synthetic training sequences are sampled from a biologically realistic Zipfian power-law distribution ($s = 1.6$): $$P(L_{\text{indel}} = k) = \frac{k^{-1.6}}{\sum_{n=1}^{L_{\max}} n^{-1.6}}, \quad k \in \{1, 2, \dots, L_{\max}\}$$

High-Speed Repeat Sequence Mining (REminerII · PixelRE) & MFC Visualization Suite

To discover interspersed repeat elements (e.g., Alu, LINE, SINE—which account for over half of the human genome) at chromosome scale, Theme 2 provides two complementary mining engines:

  • REminerII (Insilico.py:74): Built on a C++ core engine and Python pipeline, Setparam() (Insilico.py:40) configures default parameters of seed length WORD_SIZE = 14, mismatch tolerance ALLOW_SIZE = 1, merge spacing SPACE_SIZE = 2, minimum seed length MIN_SEED_LEN = 28, and early-termination threshold GREEDY_X = 30. During Greedy X-Drop extension, if the current alignment score drops by $X_{\text{drop}} = 30$ or more below the running maximum, extension terminates immediately to prune unproductive search branches.
  • PixelRE (PixelRE.m:3): Projects the sequence homology matrix into a 2D binary dot-plot image and applies multi-scale sliding windows w = [7, 8, 10, 12, 14] with morphological diagonal filtering to rapidly extract both forward and reverse-complement repeat clusters.
  • 11 Win32 MFC / DirectX Visualization Suites (RE_*): Includes 11 standalone C++/MFC submodules—such as RE_viewer, RE_heatmap, and RE_renderer—for real-time desktop rendering of massive repeat density maps and heatmaps.

Cancer Biomarker Classifiers (REDNN · RERNN) & Population Genetics

Two downstream pipelines connect discovered repeat-element variation profiles to clinical disease risk prediction and human population evolution analysis:

  • REDNN & RERNN (REDNN.py:74, US 2019/0385696 A1 ↗): Takes a patient-specific $12{,}288$-dimensional genomic repeat-element feature vector $x \in \mathbb{R}^{12288}$ (REDNN.py:69) and classifies 4 clinical risk groups via a 6-layer fully connected deep neural network ($12288 \to 512 \to 256 \to 128 \to 64 \to 32 \to 4$ with ReLU activations and Softmax cross-entropy loss) alongside a recurrent LSTM model (RERNN).
  • Population Genetics (1092x · clustering205 · EvolDist · RepeatLengthPdf, IEEE BHI '18 ↗, IEEE EMBC '17 ↗): Computes repeated K-Word length probability density functions (PDFs) and Jukes-Cantor evolutionary distance matrices across $1{,}092$ individual human genomes from the 1000 Genomes Project as well as viral/bacterial sequences for phylogenetic tree reconstruction.

Key Takeaways · Chapter 02

  1. DQNAlign Linear-Time Alignment: Combining $W \times W$ local window observations with Agent.skip() Exact Match Skip reduces $O(N_1 N_2)$ global DP to $O(N)$ linear time and constant window memory.
  2. REminerII · PixelRE · REDNN: Seed hashing + Greedy X-Drop ($X=30$) and multi-scale dot-plots mine chromosome-scale repeat elements, feeding a 12,288-D deep neural classifier for clinical cancer risk prediction.

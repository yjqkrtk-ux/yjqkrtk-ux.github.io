심층 강화학습 서열 정렬 (DQNAlign) & 고속 유전체 마이닝

차세대 시퀀싱(NGS) 및 3세대 롱리드(PacBio, Oxford Nanopore) 기술의 발전으로 단일 리드 길이가 수만~수십만 염기쌍(bp)에 달하면서, 고전적인 전역 동적계획법(Needleman-Wunsch)의 $O(N_1 N_2)$ 시공간 복잡도는 심각한 병목이 되었습니다. 본 장에서는 송용준 박사의 학위논문 핵심 성과인 DQNAlign(agent.py:10, Learning.py:17)의 국소 슬라이딩 윈도우 MDP 정식화, Dueling Double DQN + Exact Match Skip 하이브리드 가속기, 그리고 염색체 규모 반복서열 발굴 엔진인 REminerII · PixelRE · REDNN(Insilico.py:74, PixelRE.m:3, REDNN.py:74)을 수식과 시뮬레이터로 완전 해부합니다.

  • 전역 동적계획법(Needleman-Wunsch)의 $O(N_1 N_2)$ 한계를 극복하는 국소 슬라이딩 윈도우 MDP와 Exact Match Skip을 이해한다.
  • Dueling Double DQN($128+128$ 스트림 분할), Depthwise Separable Conv, Zipfian($s=1.6$) 인델 분포 수식을 확인한다.
  • 인터랙티브 시뮬레이터(Sim 02 · Sim 03)로 DQNAlign 정렬 궤적과 REminerII / PixelRE 2D 닷플롯 시드 확장을 직접 실험한다.

전역 동적계획법의 한계와 국소 슬라이딩 윈도우 MDP 정식화

두 염기서열 $S^{(1)} = (s^{(1)}_1, \dots, s^{(1)}_{N_1})$과 $S^{(2)} = (s^{(2)}_1, \dots, s^{(2)}_{N_2})$ ($s \in \{\text{A, C, G, T}\}$)를 정렬할 때, Needleman-Wunsch 전역 동적계획법(AlignmentGenerator, QLOBAL)은 모든 $(i, j) \in [0, N_1] \times [0, N_2]$ 격자에 대해 아래 점화식을 계산합니다:

$$F(i, j) = \max \begin{cases} F(i-1, j-1) + \sigma\!\left(s^{(1)}_i, s^{(2)}_j\right) & \text{(Match / Mismatch)} \\[4pt] F(i-1, j) - d_{\text{gap}} & \text{(Deletion in } S^{(2)}\text{)} \\[4pt] F(i, j-1) - d_{\text{gap}} & \text{(Insertion in } S^{(2)}\text{)} \end{cases}$$

만약 $N_1 = N_2 = 10^5\text{ bp}$라면 격자 셀 수는 $10^{10}$개(4바이트 정수 기준 약 $40\text{ GB}$ RAM)에 달해 단일 노드 처리가 불가능합니다. DQNAlign(alignment.py:9)은 전체 격자를 메모리에 올리는 대신, 현재 정렬 헤드 좌표 $(x_t, y_t)$에서 미래 방향의 $W \times W$ 국소 부분 서열 윈도우(Local Sliding Window)만을 상태 $s_t$로 관측하여 순차적으로 최적 행동 $a_t$를 결정하는 마르코프 결정 과정(MDP)으로 문제를 재정의했습니다.

MDP 상태 · 행동 · 보상 및 Exact Match Skip 수식

  • 상태 공간 ($\mathcal{S}$): alignment.py:110 및 alignment.py:158는 현재 정렬 위치 $(x_t, y_t)$로부터 부분 서열 윈도우를 원-핫(One-Hot) 또는 2차원 매칭 맵으로 인코딩하여 신경망 입력으로 제공합니다.
  • 행동 공간 ($\mathcal{A}$, n_action = 3): $$a_t \in \{0:\text{Forward } (x_t+1, y_t+1),\;\; 1:\text{Insertion } (x_t, y_t+1),\;\; 2:\text{Deletion } (x_t+1, y_t)\}$$
  • 보상 함수 ($\mathcal{R}$): $$r_t = \begin{cases} +r_{\text{match}} & \text{if } a_t = 0 \text{ and } s^{(1)}_{x_t} = s^{(2)}_{y_t} \\ -p_{\text{mismatch}} & \text{if } a_t = 0 \text{ and } s^{(1)}_{x_t} \neq s^{(2)}_{y_t} \\ -p_{\text{indel}} & \text{if } a_t \in \{1, 2\} \end{cases}$$
  • Exact Match Skip 가속기 (agent.py:82, agent.py:96, agent.py:110): 유전체 서열의 상동 구간에서는 연속된 염기 일치(Exact Match Run)가 빈번하게 나타납니다. Agent.skip()은 $s^{(1)}_{x_t} = s^{(2)}_{y_t}$인 동안 신경망 호출 없이 대각선 전진을 루프로 수행하며, 불일치(Mismatch 또는 Indel 경계)가 발생한 지점에서만 Dueling Double DQN 에이전트를 호출합니다.

Dueling Double DQN & Depthwise Separable Conv 아키텍처

Learning.py:17에는 표준 합성곱 기반 Qnetwork와 경량 깊이별 분리 합성곱(Depthwise Separable Convolution, Learning.py:88)을 적용한 SSDnetwork 및 차분 특징 기반 DiffSSDnetwork(Learning.py:171)가 구현되어 있습니다.

  1. Dueling Stream Split (Learning.py:52): 마지막 합성곱 계층의 출력 벡터 $h \in \mathbb{R}^{256}$ (h_size = 256)을 절반씩 분할하여 행동 이점 스트림 $\text{streamAC} \in \mathbb{R}^{128}$와 상태 가치 스트림 $\text{streamVC} \in \mathbb{R}^{128}$를 생성하고, 아래 수식으로 $Q(s, a; \theta)$를 결합합니다: $$Q(s, a; \theta) = V(s; \theta_V) + \left( A(s, a; \theta_A) - \frac{1}{|\mathcal{A}|} \sum_{a'=0}^{|\mathcal{A}|-1} A(s, a'; \theta_A) \right)$$
  2. Double Q-Learning 타깃 (agent.py:77): 단일 네트워크의 max 연산으로 인한 Q-값 과대추정(Overestimation Bias)을 막기 위해 행동 선택은 메인 네트워크 $\theta$로, 가치 평가는 타깃 네트워크 $\theta^-$로 분리합니다: $$y_t = r_t + \gamma \, Q\!\left(s_{t+1}, \arg\max_{a'} Q(s_{t+1}, a'; \theta_t);\; \theta^-_t\right), \quad \gamma = 0.99$$
  3. Polyak 소프트 타깃 업데이트 & Zipfian 인델 분포 (alignment.py:42): 타깃 네트워크는 매 학습 스텝마다 $\theta^- \leftarrow \tau \theta + (1-\tau)\theta^-$ ($\tau = 0.001$)로 부드럽게 갱신되며, 합성 학습 서열의 인델 길이는 실제 생물학적 진화 모델을 반영한 지프 분포(Zipfian Power-Law, $s = 1.6$)에서 샘플링됩니다: $$P(L_{\text{indel}} = k) = \frac{k^{-1.6}}{\sum_{n=1}^{L_{\max}} n^{-1.6}}, \quad k \in \{1, 2, \dots, L_{\max}\}$$

고속 반복서열 마이닝 (REminerII · PixelRE) 및 MFC 시각화 스위트

인간 유전체의 절반 이상을 차지하는 산재 반복서열(Interspersed Repeat Elements, 예: Alu, LINE, SINE)을 염색체 규모에서 발굴하기 위해, Theme 2는 두 가지 상호보완적 엔진을 제공합니다:

  • REminerII (Insilico.py:74): C++ 코어 엔진과 파이썬 파이프라인으로 구성되며, Setparam()(Insilico.py:40)이 기록하는 기본 파라미터는 시드 길이 WORD_SIZE = 14, 허용 불일치 ALLOW_SIZE = 1, 병합 간격 SPACE_SIZE = 2, 최소 시드 길이 MIN_SEED_LEN = 28, 그리고 확장 조기 종료 임계값 GREEDY_X = 30입니다. Greedy X-Drop 확장 시 현재 점수가 최고점 대비 $X_{\text{drop}} = 30$ 이상 하락하면 즉시 탐색을 멈춰 불필요한 확장을 차단합니다.
  • PixelRE (PixelRE.m:3): 서열 상동성 행렬을 2차원 닷플롯(Dot-Plot) 이진 영상으로 투영한 뒤, 다중 스케일 윈도우 w = [7, 8, 10, 12, 14]와 형태소(Morphological) 대각선 필터링을 적용하여 정방향 및 역상보 반복서열 클러스터를 고속 추출합니다.
  • 11종 Win32 MFC / DirectX 가시화 스위트 (RE_*): 대용량 반복서열 밀도 맵과 히트맵을 데스크톱에서 실시간 렌더링하기 위해 RE_viewer, RE_heatmap, RE_renderer 등 11개의 독립 C++/MFC 서브모듈이 함께 구축되어 있습니다.

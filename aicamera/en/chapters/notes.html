6.2 Single-Source-of-Truth Build Policy & Automated Verification

The entire guidebook (docs/index.html, docs/aicamera_architecture_spec.html, docs/chapters/*.html, docs/en/**, docs/css/*, docs/js/*) is deterministically generated by build_spec_portal.py rather than hand-edited HTML.

1. Metrics Loaded Directly from JSON

LSP hardware latencies, DIV2K fidelity metrics, 12MP 4-Tier ISP latencies, Universal CFA simulation results, and 10-camera White-Box Latent ISP benchmarks are parsed directly from canonical JSON files at build time and injected into tables and charts.

2. Register Defaults Parsed from C

The OpenISPParams and OpenISP3AParams default tables in Ch.03 are generated by regex-parsing the struct initialization assignments in openisp_params.h and openisp_3a.c.

3. Build-Time Integrity Gate

The build fails immediately if any referenced source path is missing, any function/line anchor cannot be resolved, any HTML tag is unclosed, any TeX math expression has unbalanced braces, or any SVG text overflows its container.

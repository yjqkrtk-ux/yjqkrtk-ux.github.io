5.2 Single-Source-of-Truth 빌드 원칙과 자동 검증

가이드북 전체(docs/index.html, docs/aicamera_architecture_spec.html, docs/chapters/*.html, docs/css/*, docs/js/*)는 수작업 HTML 편집이 아니라 build_spec_portal.py 스크립트에 의해 결정론적으로 생성됩니다.

1. 수치는 JSON에서 직접 로드

LSP 하드웨어 지연, DIV2K 화질, 12MP 4-Tier ISP 지연, Universal CFA 시뮬레이션 결과는 모두 빌드 시점에 정본 JSON 파일을 파싱해 표와 차트에 주입합니다.

2. 레지스터 기본값은 C 소스 파싱

Ch.03의 OpenISPParams와 OpenISP3AParams 기본값 표는 openisp_params.h와 openisp_3a.c의 할당문을 정규식으로 직접 읽어 생성합니다.

3. 빌드 타임 무결성 게이트

존재하지 않는 소스 파일 경로, 찾을 수 없는 함수/라인 앵커, 닫히지 않은 HTML 태그, 수식 내부의 괄호 불일치나 한글 혼입이 단 하나라도 발견되면 빌드가 즉시 실패합니다.

5.3 AICAMERA 핵심 기술 용어집 (Interactive Glossary)

가이드북 본문에서 점선 밑줄로 표시되는 모든 핵심 용어의 정의와 영문 표기, 관련 챕터 링크입니다. 검색창에 한글·영문·약어 키워드를 입력하면 실시간으로 필터링됩니다.
